## About The Project

Smart village governance web portal enabling residents to request official administrative certificates online, view village development budget allocations, and access local UMKM directories.

---

## Key Features

- Online Certificate Request (Surat Pengantar): Request SKCK, Surat Domisili, and Surat Keterangan Usaha digitally.
- Village Budget Visualizer (APBDes): Transparent chart breakdown of village revenue and infrastructure expenditures.
- Local Citizen Census Directory: Population statistics grouped by gender, age bracket, and employment sectors.
- Village News and Announcements: Official bulletin for community events and aid distribution schedules.

---

## Technology Stack

- Backend: Laravel 10 (PHP 8.2)
- Database: MySQL 8.0
- Frontend: Blade Templates and Tailwind CSS

## Getting Started

`ash
git clone https://github.com/raphlv/igakerta.git
cd igakerta
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
`
